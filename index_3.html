Full-stack · graph and matching algorithms

Penn Four Year Planner

A degree planner for ten Penn programs that checks a four year plan against the catalog's real rules, not a credit total.

Prerequisites are transcribed from the Penn catalog and stored in conjunctive normal form, so the server evaluates a whole plan as a boolean expression and reports not just which course is out of order but the term it would have to move to. The degree audit is a maximum bipartite matching rather than a sum, because Penn's own footnote says a course may count only once: matching spends each course exactly once and shows which course paid for which requirement, where summing would let one course satisfy two rows and call an unfinished plan complete. The ten degrees are stored as data rather than code, so the same plan can be re-audited against another major to show what carries over, what stops counting, and how many extra semesters it would cost.

10 degrees, two schools 209 courses transcribed 285 tests and browser checks

Full-stack · ML relevance ranking

Research Radar

Aggregates new papers from bioRxiv, arXiv and PubMed, and ranks them against a researcher's own topics.

The API normalizes three heterogeneous JSON and XML source formats into one schema and fetches all sources concurrently. Ranking is measured rather than asserted: three rankers, weighted keyword, TF-IDF cosine and Okapi BM25, all implemented in numpy, are scored against a committed labelled fixture set by an offline harness reporting Precision@k, MRR and NDCG@10, so a change to the ranker can be shown to help or not.

~3x faster via concurrent fetch 3 rankers, benchmarked offline 41 tests

Distributed systems

Distributed Key-Value Store

The Raft consensus algorithm implemented from scratch in Go, with a key-value layer on top.

Leader election with PreVote, log replication, commit safety and log compaction via snapshotting. State is written to stable storage before any RPC is answered, so a crashed node recovers its term, vote and log rather than coming back blank, which is what stops one term from electing two leaders. The key-value layer adds exactly-once client semantics, closing the window where a retried Append would otherwise be applied twice. An in-memory network simulator injects crashes, partitions and full restarts to prove it.

29 tests, race-clean 0 data loss across crash, partition, restart

Bioinformatics · full-stack

Single-Cell RNA-seq Explorer

Turns a table of thousands of cells by thousands of genes into an interactive map you can actually read.

Runs the standard single-cell pipeline (QC, normalization, PCA, Leiden clustering, UMAP and marker-gene detection) and renders thousands of cells as an interactive UMAP coloured by cluster or by any gene. Adds the quality-control panel an analyst actually checks first: per-cell gene and count distributions, mitochondrial and ribosomal fractions, and a simulation-based doublet score written in numpy, which flags droplets that captured two cells. A canvas scatter renderer and a lazily imported analysis layer keep the hosted demo light, with live upload-and-analyze of .h5ad and .csv datasets.

Python · FastAPI · scanpy · React · Canvas Live Source
