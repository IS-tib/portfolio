Full-stack · ML relevance ranking

Research Radar

A full-stack app (React + FastAPI) that aggregates new papers from bioRxiv, arXiv, and PubMed and ranks them by relevance to a user's research topics. The API normalizes three heterogeneous JSON/XML source formats into one schema and fetches all sources concurrently. Ranking is measured rather than asserted: three rankers (weighted keyword, TF-IDF cosine, and Okapi BM25, all implemented in numpy) are scored against a committed labelled fixture set by an offline harness reporting Precision@k, MRR and NDCG@10, so a change to the ranker can be shown to help or not.

Distributed systems

Distributed Key-Value Store

The Raft consensus algorithm implemented from scratch in Go: leader election with PreVote, log replication, commit safety, and log compaction via snapshotting. State is written to stable storage before any RPC is answered, so a crashed node recovers its term, vote and log rather than coming back blank, which is what stops one term from electing two leaders. The key-value layer adds exactly-once client semantics, closing the window where a retried Append would otherwise be applied twice. An in-memory network simulator injects crashes, partitions and full restarts to prove it.

Bioinformatics · full-stack

Single-Cell RNA-seq Explorer

A full-stack app that runs the standard single-cell RNA-seq pipeline (QC, normalization, PCA, Leiden clustering, UMAP, and marker-gene detection) and renders thousands of cells as an interactive UMAP colored by cluster or by any gene. Adds the quality-control panel an analyst actually checks first: per-cell gene and count distributions, mitochondrial and ribosomal fractions, and a simulation-based doublet score written in numpy, which flags droplets that captured two cells. A canvas scatter renderer and a lazily-imported analysis layer keep the hosted demo light, with live upload-and-analyze of .h5ad / .csv datasets.
